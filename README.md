# Wall Play

Аркада в духе **Wall Kickers**: ниндзя прыгает между двумя стенами вертикальной шахты и лезет как можно выше.

Открой `index.html` в браузере. Ничего устанавливать не нужно: один файл, без зависимостей. Работает на телефоне и на компьютере.

## Управление
- **Тап / клик / Пробел / ↑**: прыжок от стены к противоположной стене.
- **Тап в воздухе**: двойной прыжок с сальто и **разворотом** обратно (один раз за прыжок).
- **P / Esc**: пауза, **M**: звук.

## Что есть
- Стены: обычные, **шипы** (смерть), **лёд** (быстрое скольжение), **крошащиеся блоки** (обваливаются через полсекунды), **провалы** (держаться не за что).
- Враги и ловушки: летучие мыши, циркулярные пилы, падающие камни с предупреждением «!».
- Монеты и щит, который спасает от одного удара.
- Зоны с разным оформлением по высоте: шахта, мшистые глубины, ледяной колодец, лава, храм, небесная башня.
- Сложность растёт с высотой.
- Рекорд и отметка рекорда на стене, копилка монет, магазин героев (5 скинов). Всё сохраняется в `localStorage`.
