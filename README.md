# Wall Play

Аркада в духе **Wall Kickers**: ниндзя прыгает между двумя стенами вертикальной шахты и лезет как можно выше.

Открой `index.html` в браузере. Ничего устанавливать не нужно: один файл, без зависимостей. Работает на телефоне и на компьютере.

## Управление
- **Нажми**: прыжок от стены (или с земли).
- **Держи**: длинный и высокий прыжок.
- **Нажми в воздухе**: сальто с разворотом (один раз за прыжок).
- **P / Esc**: пауза, **M**: звук и музыка.

## Что есть
- Яркая пиксельная графика: стволы-брёвна, кроны, травяные уступы, птички, облака и падающие листья.
- Уровень не из двух стен: проход постоянно сдвигается, есть уступы, на которые можно приземлиться, нависающие потолки и бревна-столбы посередине.
- Анимированный герой: стоит, моргает, бежит по уступам, цепляется за стену и медленно съезжает, прыгает, крутит сальто.
- Ловушки: колючки на стенах, пчёлы, колючие шары, падающие шишки с предупреждением «!».
- Монеты, щит, зоны по высоте (лес, осень, снег, пляж, конфетная страна, звёздная ночь).
- Фоновая чиптюн-песенка и звуки, всё генерируется в браузере.
- Рекорд, копилка монет и магазин из 6 героев, всё сохраняется в `localStorage`.
